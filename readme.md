# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This project focuses on predicting house prices using Machine Learning techniques. The model is trained on a real-world housing dataset and aims to estimate property prices based on features such as area, number of bedrooms, bathrooms, furnishing status, parking availability, air conditioning, and other amenities.

The project includes complete data preprocessing, exploratory data analysis (EDA), visualization, model training, evaluation, and comparison between multiple regression algorithms.

---

## 🎯 Objectives

* Perform data cleaning and preprocessing.
* Explore the dataset using statistical analysis and visualizations.
* Identify the factors that influence house prices.
* Train and evaluate multiple regression models.
* Compare model performance using standard evaluation metrics.

---

## 📂 Dataset

**Source:** Kaggle Housing Prices Dataset ```https://www.kaggle.com/datasets/yasserh/housing-prices-dataset```
